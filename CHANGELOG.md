## Unreleased

## [0.2.0] - 2026-05-07

### Added

- YAML schema validation pipeline for `config/*.yaml` using `scripts/validate_config.py`
- Sonar-compatible validation report generation (`reports/sonar-issues.json`)
- Repository guidance in `.github/copilot-instructions.md`
- `/add-repository` skill in `.github/skills/add-repository/SKILL.md` to standardize onboarding/import flows
- Consolidated `CI Summary` job with visibility on YAML validation, tfvars generation, validate, tests, plan, and lint results

### Changed

- CI flow updated to run OpenTofu format checks before tfvars generation
- CD flow updated to consume approved plan artifacts generated by CI (`workflow_run`)
- GitHub authentication in CI/CD migrated from static PAT usage to short-lived GitHub App installation tokens
- Workflow permissions moved from workflow level to job level to enforce least privilege

### Fixed

- GitHub provider token wiring in OpenTofu provider configuration
- Plan output capture and PR comment rendering reliability in CI
- Branch protection default alignment for `require_signed_commits` between generated tfvars and module behavior
- Explicit warning/logging for skipped `example*.yaml` files during tfvars generation
- Removed manual `tofu fmt` invocation from tfvars generator script in favor of CI-based formatting checks

## [0.1.0] - 2026-05-06

### Added

- Initial IaC repository structure for managing GitHub repositories with OpenTofu
- CI/CD workflows for validation, testing, planning, and apply
- Pre-commit hooks and Dependabot configuration
